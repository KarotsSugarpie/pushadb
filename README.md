# PushADB

Windows desktop utility for managing authorized Android TV / Fire TV devices over ADB.

Features: connect using IP/port, list devices, install an APK, inspect device, manage common configuration actions, and review command logs. Requires Android debugging authorization on the target device.

See the **Actions** tab for Windows builds after source files are added. The build uploads a portable executable as an artifact.

Only connect to and administer devices you own or have permission to manage.
